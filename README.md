# Mahmoud Salem — Portfolio

A responsive one-page portfolio for an AI Engineering student.

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and reveal animations

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize before publishing
1. Replace the GitHub and LinkedIn placeholder URLs in `index.html`.
2. Add real project GitHub links if you have them.
3. Add a profile photo if desired.
4. Update project descriptions as your portfolio grows.

## Deploy
This static site can be hosted on GitHub Pages, Netlify, Vercel, or any static web host.
